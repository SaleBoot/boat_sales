========================================
    船舶定制系统 - 项目说明
    Maritime Atelier Yacht Customization
========================================

【项目概述】
本系统是一个船舶展示与定制平台，参考苹果公司的设计理念，
采用简洁、克制、注重排版与留白的视觉风格。
用户可以浏览六款精选船型，查看详细参数，
或进入三步定制流程，打造专属海上座驾。

【设计理念】
- 视觉风格：Apple Design Language
- 字体体系：SF Pro Display / PingFang SC
- 配色方案：以 #0071e3（Apple Blue）为主色调，
  背景采用 #fbfbfd / #f5f5f7 双层灰白
- 动效语言：cubic-bezier 缓动曲线，卡片渐入、
  悬停浮起、磨砂玻璃导航栏
- 响应式：支持桌面、平板、移动端三档断点

【技术栈】
- 前端：HTML5 + CSS3 + Vanilla JavaScript（无框架依赖）
- 后端：Node.js + Express
- 通信：RESTful JSON API

【目录结构】
船舶定制系统/
├── server.js              → Express 后端服务器
├── package.json           → 项目依赖与脚本
├── 项目说明.txt           → 本文件
└── public/                → 前端静态资源
    ├── index.html         → 页面入口
    ├── css/
    │   └── style.css      → Apple 风格样式
    ├── js/
    │   └── app.js         → 前端交互逻辑
    └── assets/            → 静态资源目录

【API 接口】
1. GET  /api/boats            → 获取全部船型（支持 ?type= 筛选）
2. GET  /api/boats/:id        → 获取单个船型详情
3. GET  /api/customize/options → 获取定制选项（颜色/内饰/动力/附加配置）
4. POST /api/customize         → 提交定制方案，返回订单号与总价
5. GET  /api/health            → 健康检查

【船型数据】
1. Azure Flybridge    - 飞桥豪华游艇  - 18.5米 - ¥2,800万
2. Velocity Sport     - 运动快艇      - 12.8米 - ¥980万
3. Island Catamaran   - 双体游艇      - 15.2米 - ¥1,950万
4. Pathfinder Explorer - 探险游艇    - 24.0米 - ¥4,600万
5. Heritage Classic   - 经典游艇      - 16.5米 - ¥1,680万
6. Majesty Supreme    - 超级豪华游艇  - 30.0米 - ¥7,200万

【启动方式】
1. 进入项目目录：cd 船舶定制系统
2. 安装依赖：npm install
3. 启动服务：npm start
4. 浏览器访问：http://localhost:3000

【功能说明】
- 船型浏览：左侧导航「船型」→ 网格展示，点击卡片查看详情
- 船型筛选：侧边栏按类型筛选（飞桥/运动/双体/探险/经典/豪华）
- 定制流程：左侧导航「定制船型」→ 三步向导
  步骤1：选择基础船型
  步骤2：配置船体颜色、内饰风格、动力系统、附加配置
  步骤3：确认方案，查看总价，提交生成订单号
- 详情弹窗：点击任意船型卡片，弹出磨砂玻璃模态框

【环境要求】
- Node.js >= 14.0.0
- 现代浏览器（Chrome / Safari / Edge / Firefox）

2026-08-31  修复定制图纸管理图片无法查看问题
------------------------------
  问题：上传含中文文件名的图纸后，图纸管理中点击文件链接无法查看图片。
  原因：multer 处理 file.originalname 时存在 Latin-1 与 UTF-8 双重编码问题，
        导致磁盘上的文件名出现乱码字节，API 返回的 savedAs 与磁盘实际文件名不匹配，
        浏览器请求 /uploads/路径 时返回 404。

  修改：
  1. server.js — multer storage filename 函数改为仅使用扩展名
     - 原逻辑：uniqueSuffix + '-' + file.originalname（含中文，导致乱码）
     - 新逻辑：uniqueSuffix + path.extname(file.originalname)（纯 ASCII 文件名）
     - fileFilter 同步改用 path.extname() 提取扩展名

  2. server.js — uploadRecords.originalName 修复编码
     - 使用 Buffer.from(f.originalname, 'latin1').toString('utf8') 正确解码中文文件名
     - 确保前端显示的 originalName 为正确的中文

  3. members.js — 图纸文件链接增加 encodeURIComponent
     - href="/uploads/${encodeURIComponent(f.savedAs)}" 防止特殊字符导致 URL 解析错误

  4. 磁盘文件清理 — 重命名已存在的乱码文件为纯 ASCII 文件名

  涉及文件：server.js / members.js

2026-08-31  登录页水波纹效果增强
------------------------------
  问题：水波纹分辨率低（像素颗粒感明显），交互效果不够写实。

  ripple.js — 全面重写水波纹算法

  2. 双线性插值采样高度图（sampleHeight），消除方块感
  3. 镜面高光：根据波面梯度计算高光强度，波峰自动反光
  4. 色散效果：高光中 R/G/B 通道不同权重，模拟水面光散
  5. 折射强度 8→12，波纹扭曲更明显
  6. 阻尼 0.985→0.988，波纹持续更久更自然
  7. 环境波纹：每 ~80 帧随机产生微弱涟漪，水面持续活跃
  8. 扰动半径 3→4，波纹生成更平滑
